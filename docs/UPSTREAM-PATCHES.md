# Patches to BentoPDF code

Paperwing keeps BentoPDF's code unmodified wherever possible, so new BentoPDF releases merge in
cleanly. The exceptions are listed here. When merging a BentoPDF release, check whether upstream
has fixed each one; if it has, take upstream's version and remove the entry.

| File                                          | Change                                                                                                                                                                                                                                                                                                                       | Why                                                                                                                                                                                                                                                                                                       |
| --------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `vite.config.ts`                              | Two lines registering `reskin/vite-plugin-reskin.ts`                                                                                                                                                                                                                                                                         | Injects Paperwing's integration layer at build time                                                                                                                                                                                                                                                       |
| `src/js/editcore/streamsplice.js`             | The `TJ` array pattern in `showOperators` no longer lets a backslash match two ways                                                                                                                                                                                                                                          | Catastrophic regex backtracking (ReDoS) on crafted PDF content streams (CodeQL `js/redos`)                                                                                                                                                                                                                |
| `src/js/editcore/type3surgery.js`             | The array branch of `TOKEN_RE` no longer lets `(` and `<` match both as string/hex starts and as plain characters                                                                                                                                                                                                            | Same ReDoS class (CodeQL `js/redos`)                                                                                                                                                                                                                                                                      |
| `src/js/editcore/app.js`                      | The `?demo=<file>` debug loader is removed (`demo` is always `null`, so the debug hooks that need it stay off)                                                                                                                                                                                                               | Fetching a URL taken from the page's address invites request forgery (CodeQL `js/client-side-request-forgery`); nothing uses it                                                                                                                                                                           |
| `src/js/utils/markdown-editor.ts`             | Mermaid's SVG output is re-sanitized with DOMPurify using Mermaid's strict settings (labels are kept)                                                                                                                                                                                                                        | Defence in depth before `innerHTML` (CodeQL `js/xss-through-dom`)                                                                                                                                                                                                                                         |
| `src/js/logic/edit-pdf-text-page.ts`          | In Paperwing's desktop app, Export doesn't show "PDF saved successfully" or close the editor                                                                                                                                                                                                                                 | The result opens in a new tab (the workspace says so); closing the editor went back to the upload screen, which the workspace hides, leaving a blank page                                                                                                                                                 |
| `src/js/utils/markdown-editor.ts`             | In Paperwing's desktop app, Export PDF hands the print-styled page to `reskin/export-pdf.ts` (`exportPdfToShell`) instead of calling `print()`; Paperwing's `getStyledHtml` styles it (with KaTeX's styles since 2.8.11, which prints the page with its own CSS instead)                                                     | There, `print()` opens Chromium's print dialog, which can't preview or print in the desktop app; the page is made into a PDF that opens as a document. In a browser, `print()` is still used                                                                                                              |
| `src/js/logic/validate-signature-pdf.ts`      | RSA PKCS#1 v1.5 signatures are verified with Web Crypto only, not node-forge (since 2.8.11 upstream tries node-forge first for keys with an exponent above 3; Paperwing doesn't, whatever the exponent)                                                                                                                      | node-forge accepts malformed DigestInfo, so forged signatures could validate ([GHSA-86w9-cpqp-85rv](https://github.com/advisories/GHSA-86w9-cpqp-85rv)); no fixed release exists. The key had come from the first certificate listed, so a valid signature whose signer wasn't first showed as unverified |
| `src/js/logic/validate-signature-pdf.ts`      | Certificates with ECDSA keys are read (forge reads only RSA ones: a stand-in key, the real one is taken from the certificate's own bytes); the signer's certificate is matched by its issuer as written, not as forge re-encodes it; trust is checked against one certificate or several (DER), ECDSA chains with Web Crypto | Paperwing's ECDSA signatures (smart cards, ID cards) showed as broken; a certificate with an email address in its issuer wasn't found ("Could not parse signer info"); the desktop app can trust the system's root certificates                                                                           |
| `src/js/logic/validate-signature-pdf-page.ts` | In Paperwing's desktop app, an option to trust the root certificates in the Windows certificate store or the Keychain (`src/reskin/system-trust.ts`), off by default                                                                                                                                                         | Acrobat's option: a company's own certificates show as trusted                                                                                                                                                                                                                                            |
| `scripts/security-patterns-check.mjs`         | File-name filter rewritten without an ambiguous regex                                                                                                                                                                                                                                                                        | CodeQL `js/regex/missing-regexp-anchor` (behaviour unchanged)                                                                                                                                                                                                                                             |
| `src/js/editcore/app.js`                      | A paragraph's own embedded font is only re-linked to spans still in that paragraph's family (`applyDocFonts`)                                                                                                                                                                                                                | Changing a paragraph's font in Edit a PDF kept drawing it, and exporting it, in the old font                                                                                                                                                                                                              |
| `src/js/editcore/app.js`                      | A run set in another font is passed to the engine without its source run (`spanStyle`, `styleTargetRuns`)                                                                                                                                                                                                                    | The engine reuses a run's source font and only looks up a new one for runs without a source, so changing the font of existing text did nothing on screen or in the saved file                                                                                                                             |
| `src/js/editcore/core.js`                     | Tabs in the engine's page text read as spaces (`spaceTabs`)                                                                                                                                                                                                                                                                  | Some PDFs (wkhtmltopdf's) map their space character to a tab; editing such a page broke its lines apart                                                                                                                                                                                                   |
| `src/js/utils/wasm-provider.ts`               | An engine URL given as a path (`/engines/…`) is resolved against the page's origin                                                                                                                                                                                                                                           | The desktop app bundles PyMuPDF, Ghostscript and coherentpdf instead of loading them from a CDN                                                                                                                                                                                                           |
| `src/js/logic/edit-pdf-page.ts`               | Inside Paperwing (`rs-embedded`), the viewer's Open, Close, Print and Protect actions and its tab bar are off (since 2.8.11 upstream's Export saves through `downloadEditedPdf`, so it stays on)                                                                                                                             | They duplicate the workspace                                                                                                                                                                                                                                                                              |
| `src/js/logic/sign-pdf-page.ts`               | The Highlight tool is no longer selected when the viewer opens                                                                                                                                                                                                                                                               | Fill & Sign opened with Highlight on, so the first click on a page highlighted text                                                                                                                                                                                                                       |
| `src/js/logic/add-stamps.ts`                  | Inside Paperwing (`rs-embedded`), saving the stamped PDF doesn't reset the tool                                                                                                                                                                                                                                              | The result opens as a new document and the tool stays on the open one, whose upload screen it hides                                                                                                                                                                                                       |
| `src/js/logic/ocr-pdf-page.ts`                | English is ticked when the language list first appears                                                                                                                                                                                                                                                                       | Start OCR was disabled, with nothing saying a language had to be chosen first                                                                                                                                                                                                                             |
| `src/js/utils/tesseract-runtime.ts`           | Self-hosted paths (`/engines/…`) are made absolute; with `VITE_TESSERACT_BUNDLED_LANGUAGES`, a run needing a language that isn't bundled takes all its languages from Tesseract's default CDN                                                                                                                                | The desktop app bundles the OCR engine and English only                                                                                                                                                                                                                                                   |
| `src/js/utils/font-loader.ts`                 | `VITE_OCR_BUNDLED_FONTS` families load from `VITE_OCR_BUNDLED_FONT_BASE_URL`; others from their usual source                                                                                                                                                                                                                 | OCR's Latin text-layer font (Noto Sans) ships with the app                                                                                                                                                                                                                                                |
| `src/js/editcore/engine-loader.js`            | Outside the browser (tests), the engine's WebAssembly path is a real file path on Windows too                                                                                                                                                                                                                                | It was `/D:/…`, which Windows read as `D:\D:\…`, so the editor engine tests couldn't load it                                                                                                                                                                                                              |

The upstream commits Paperwing cherry-picked before 2.8.11 (the annotation viewer's origin check, signature dictionaries without /Type, scanner XPS files, Merge's notifications, wide tables in Markdown to PDF) are part of BentoPDF 2.8.11, merged in full.

## Paperwing's name in BentoPDF's tools

BentoPDF's pages, code and interface strings show its name in places (page titles, messages,
the Markdown editor's sample, the files some tools save). `reskin/brand.mjs` puts Paperwing's
name there while building: `reskin/vite-plugin-reskin.ts` for the pages and `src/js` code,
`desktop/scripts/build-web.mjs` for `dist/locales` (keys too: `ui.json` is keyed by the English text, which the code looks up rebranded). BentoPDF's files aren't changed.

Kept as they are: BentoPDF's copyright notices (any line with "©" or "All rights reserved"), web
addresses and storage keys (lowercase, so existing settings carry over), and the credits (README,
NOTICE.md, the About box). `desktop/bench/check-branding.mjs` fails if the build shows BentoPDF's
name anywhere else; `check-tools.mjs` checks what every tool shows in the running app, including
BentoPDF's website content (self-hosting, sponsors, Discord). When a BentoPDF release adds a
file its tools save under its name, add it to `FILE_NAMES` in `brand.mjs`.

## Patches to the viewer package

The EmbedPDF viewer (`bentopdf-viewer`, a BentoPDF dependency) is patched while
building, by `reskin/vite-plugin-reskin.ts`; the package itself isn't changed.
Each patch checks that the code it replaces is there exactly as expected and is
skipped with a warning otherwise (for example after a viewer update).
`PAPERWING_VIEWER_PATCHES=0` builds without them.

| Patch          | Why                                                                                                                                                                                     |
| -------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| State snapshot | The viewer's store copied its whole state on every read, once per listener on every change: half of the main thread while scrolling. One snapshot per change now                        |
| Wheel zoom     | Ctrl+mouse wheel zoomed out to the minimum in one notch (and doubled per notch in). About 15% per notch now, eased; trackpad pinches unchanged                                          |
| Tab spaces     | PDFs whose space character is a tab (wkhtmltopdf's): copied text was full of tabs and phrase searches found nothing. Tabs read as spaces; phrase searches on such pages also match tabs |
| Font faces     | Fonts a PDF doesn't embed were all drawn in one sans-serif face. Latin text now gets a fallback chosen by name with matching widths (Liberation Serif/Sans/Mono, Carlito, Caladea)      |

`zgapdfsigner` (timestamps, digital signatures) is patched the same way:

| Patch                | Why                                                                                                                                                                                                                                                                                                                                                                                                                       |
| -------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Signer browser check | Its browser detection is never true inside a bundled module, so it didn't use `fetch` and refused the desktop app's relay for timestamp servers                                                                                                                                                                                                                                                                           |
| External signer      | It only signs with a key read from a .pfx. With `pwExternal` in its options it prepares the PDF as before (field, appearance, byte range, adding to a signed PDF, DSS) and takes the signature from Paperwing's CMS builder (`src/acro/certs/cms.ts`), whose key is held by Windows, the Keychain, a smart card or a file; also the SubFilter, the app's name and Lock document after signing. Without it nothing changes |

These are in `reskin/signer-patches.ts` and are applied whatever `PAPERWING_VIEWER_PATCHES` says (the
desktop app's certificate signing needs them). The unit tests load zgapdfsigner with the same
patches (`src/tests/helpers/zga-patched.ts`) and fail if one no longer fits.
